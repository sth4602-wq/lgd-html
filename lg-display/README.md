# LG Display 한국어 랜딩 페이지

`index.html`을 브라우저에서 열면 바로 볼 수 있는 정적 사이트입니다. 별도 설치가 필요하지 않습니다.

- `index.html`: 한국어 본문과 섹션 구성
- `style.css`: 검정·붉은색 테마, 데스크톱·모바일 레이아웃
- `script.js`: 모바일 메뉴 열기·닫기 및 Escape 키 처리
- `assets/display.jpg`, `assets/oled.png`: 공식 디스플레이 이미지

## 출처

브랜드·기술 정보: https://www.lgdisplay.com/ 및 https://www.lgdisplay.com/kor/technology/oled

메인 이미지: https://www.lgdisplay.com/images/tv/oled3th/tv_kv.jpg

OLED 이미지: https://www.lgdisplay.com/images/main_re/prod1.png

이미지 및 브랜드 권리는 LG디스플레이에 있습니다. 이 페이지는 비공식 디자인 콘셉트이며 공식 사이트와의 관계를 주장하지 않습니다.

본문 서체는 Google Fonts의 Noto Sans KR을 사용하며 인터넷에 연결되지 않은 경우 시스템 sans-serif 서체로 표시됩니다.
